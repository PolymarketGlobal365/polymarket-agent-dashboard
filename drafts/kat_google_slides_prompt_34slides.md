# 구글슬라이드 생성 프롬프트

아래 지시를 그대로 따라 `2026년 코리안 아티스트 투데이 자료 기획 및 제작 대행` 제안 발표자료를 제작하라.  
목표는 `공공기관 평가위원이 15분 발표 안에 사업 이해도, 실행력, 안정성, 차별성, 수행역량을 즉시 체감하도록 만드는 것`이다.  
슬라이드는 반드시 `34페이지 이상`으로 구성하고, 내용은 제안서의 핵심을 누락 없이 반영하되 `발표용`으로 재구성한다.  
톤은 과장된 광고형이 아니라 `국가·공공기관 입찰 발표자료에 맞는 신뢰도 높은 전문형`으로 유지한다.

## 1. 전체 제작 방향

- 발표 대상: 예술경영지원센터 외부 전문평가위원
- 발표 시간: 15분 발표 + 15분 질의응답
- 발표 목표:
  - Korean Artist Today 사업의 목적과 구조를 정확히 이해하고 있음을 증명
  - 수집형 자료와 기획형 발간자료를 동시에 안정적으로 운영할 수 있음을 설득
  - 연간 운영체계, 필진 운영, 번역 품질관리, 확산 운영의 실행력을 보여줌
  - 유니트미디어의 수행역량과 실무형 조직 구성이 본 과업에 적합함을 강조
- 핵심 메시지 4가지:
  - 정확한 아카이브 운영
  - 기획력 있는 동시대 미술 콘텐츠 발행
  - 국·영문 병행 품질관리
  - 정시 납품이 가능한 연간 운영체계

## 2. 디자인 시스템

- 전체 무드:
  - 공공 제안 PT답게 신뢰감, 정제감, 구조적 명료성이 가장 중요
  - 미술 사업 발표자료이므로 너무 딱딱한 행정문서처럼 보이지 않게 `아카이브 + 현대미술 편집 디자인` 느낌을 결합
- 색상:
  - 메인 컬러: `#163A5F` 딥 네이비
  - 서브 컬러: `#4D6E8E` 스틸 블루
  - 포인트 컬러: `#B7924A` 브론즈 골드
  - 배경 컬러: `#F7F9FB`, `#FFFFFF`
  - 보조 라인 컬러: `#D5DEE7`
- 폰트:
  - 제목: `Pretendard Bold` 또는 `Noto Sans KR Bold`
  - 본문: `Pretendard Regular` 또는 `Noto Sans KR Regular`
  - 수치/강조: `Pretendard SemiBold`
- 텍스트 크기 기준:
  - 표지 메인 타이틀: `28~32pt`
  - 섹션 표지 타이틀: `24~28pt`
  - 본문 슬라이드 제목: `20~24pt`
  - 부제/설명문: `11~14pt`
  - 본문 핵심 불릿: `12~15pt`
  - 표 안 텍스트: `9.5~11pt`
  - 각주/출처: `8~9pt`
- 레이아웃 원칙:
  - 한 슬라이드에 불릿은 최대 4개
  - 표는 행 6개 이내로 끊고, 많으면 2장으로 분리
  - 텍스트 60%, 도식·박스·강조영역 40%
  - 모든 슬라이드 우하단에 페이지 번호
  - 섹션 시작 슬라이드는 풀페이지 구조로 임팩트 있게 구성
- 시각 요소:
  - 얇은 라인, 박스, 구획형 레이아웃 적극 활용
  - 원형 아이콘이나 선형 아이콘은 최소한으로만 사용
  - 과도한 애니메이션 금지
  - 배경 이미지는 넣더라도 매우 절제해서 사용
- 절대 금지:
  - 보라색 계열 메인 컬러
  - 캐주얼 스타트업 피치덱 느낌
  - 과도한 사진 콜라주
  - 텍스트가 많은데 시각적 구획이 없는 슬라이드

- 제목:
  - `2026년 코리안 아티스트 투데이 자료 기획 및 제작 대행`
- 부제:
  - `Korean Artist Today의 아카이브 운영, 기획형 발간자료 제작, 국·영문 등록, 카드뉴스 확산을 통합 수행하는 연간 실행 제안`
- 하단 정보:
  - `제안사: 유니트미디어`
  - `발표자: 서진영 대표 / PM`
- 레이아웃:
  - 좌측 정렬 대형 타이틀
  - 우측에는 얇은 라인 박스 안에 핵심 키워드 4개 배치
  - 키워드: `Archive`, `Features`, `Translation`, `Expansion`

  - 확산 및 운영관리

- 레이아웃:
  - 2열 구성
  - 각 항목 앞에 01~06 넘버링

### 3. 왜 이 사업을 우리가 맡아야 하는가

- 제목: `Why Unitmedia`
- 핵심 문장 4개:
  - `데이터 운영과 콘텐츠 기획을 동시에 수행하는 구조`

  - `기획형 발간자료의 편집·번역·디자인 통합 수행`
  - `카드뉴스·인스타그램 운영까지 연결되는 확산 체계`
- 하단 한 줄:
  - `유니트미디어는 Korean Artist Today를 ‘정보 축적형 아카이브’이자 ‘읽히는 동시대 미술 플랫폼’으로 운영할 실행형 파트너입니다.`

- 제목: `사업 이해 한눈에 보기`

  - 사업수행 역량 → 조직, 실적, 직접 수행경험
  - 지원기술 및 사후관리 → 결과물 정리, 보완 대응
- 하단:
  - `발표는 평가항목 순으로 설계해 심사위원의 채점 흐름에 맞춘다`

- 제목: `Our Core Promise`

### 12. 연간 운영 프레임

- 제목: `연간 운영 프레임`
- 도식:

- 단계별 설명:
  - 수집: 작가·전시·공간·출판물·뉴스 조사
  - 정제: 사실검증, 번역, 교정, 메타데이터 정리
  - 발행: 기사 편집, 디자인, 등록
  - 확산: 카드뉴스, SNS, 모니터링
