# Shortform 30-Shot Storyboard Template

This version is built for vertical shortform planning.

## Import this into Figma

Use this file:

[video-storyboard-figma-template-shortform-30shots.svg](/C:/Users/jyjy6/Documents/New%20project/assets/templates/video-storyboard-figma-template-shortform-30shots.svg)

Do not import the markdown guide files. Figma needs the SVG template.

## What changed from the first template

- Built for `9:16` shortform content
- Each shot card has a portrait placeholder sized for `1080 x 1920` content ratio
- Expanded from `Shot 01` to `Shot 30`
- Added shortform-specific fields like `Hook`, `CTA`, `Subtitle Zone`, and `First 3 Seconds Priority`

## Suggested Figma page structure

1. `Master 30 Shots`
2. `Alt Hooks`
3. `Kling Outputs`
4. `Final Select`

## Recommended use

- Keep the first 3 to 5 shots especially clear because they control retention.
- Use the `Shot Summary` field to write what the viewer should feel in one sentence.
- Replace the frame placeholder with stills from Kling as you generate options.
