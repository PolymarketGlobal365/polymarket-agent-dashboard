# Video Storyboard Template

This template is designed for planning an AI-assisted video in one view before you move into Kling or another generation tool.

## What the storyboard should always contain

1. `Project info`
   Title, format, runtime, target audience, delivery spec, owner, version, and date.
2. `Core message`
   One sentence for what the video is trying to say, plus the emotional takeaway or CTA.
3. `Style and continuity`
   Visual tone, lighting, color direction, location rules, character styling, and props that must stay consistent.
4. `Watch-outs`
   Things that must not happen: broken continuity, wrong era, wrong brand use, impossible camera move, missing asset, legal issue, or unclear story beat.
5. `Transition key`
   A simple legend for the transition language used across the board.
6. `Shot cards`
   Each shot should show the frame, shot purpose, action, camera/framing, transitions, and audio cue.

## Recommended shot-card fields

Use these fields for every card so the board stays readable:

- `Shot number`
- `Duration`
- `Status`
- `Frame / Still / Reference`
- `Shot purpose`
- `Action / Beat`
- `Camera / Framing`
- `In / Out transition`
- `Dialog / SFX / Music`

## A practical fill-in method

Write the board in this order:

1. Fill in `Core message` first.
2. Define `Style and continuity` so every shot inherits the same world.
3. Add the six most important shots first, even if the project will grow later.
4. For each shot, write the purpose in one line before you describe visuals.
5. Add transitions only after the sequence order is clear.
6. Use `Watch-outs` for anything that tends to break during AI video generation.

## Suggested status labels

Keep status short and visual:

- `Planned`
- `Prompting`
- `Generated`
- `Selected`
- `Revise`
- `Final`

## Suggested transition shorthand

Use a small, fixed vocabulary:

- `Cut`
- `Match Cut`
- `Fade In`
- `Fade Out`
- `Dissolve`
- `Whip Pan`
- `Speed Ramp`
- `Hold`

## Figma setup

Import [video-storyboard-figma-template.svg](/C:/Users/jyjy6/Documents/New%20project/assets/templates/video-storyboard-figma-template.svg) into Figma, then:

1. Ungroup once or twice only if you need layout freedom.
2. Duplicate a `Shot` card when you need more than six shots.
3. Replace each `Frame / Still / Reference` area with generated stills from Kling.
4. Keep one page for `Master Board` and one page for `Alt Versions`.

## Why this structure works

It keeps the creative brief, production risk, sequence logic, and shot-level execution on the same board. That is usually the fastest way to avoid making pretty shots that do not add up to a clear video.
