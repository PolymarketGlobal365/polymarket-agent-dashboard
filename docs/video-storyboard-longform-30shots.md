# Longform 30-Shot Storyboard Template

This version is built for horizontal longform planning.

## Import this into Figma

Use this file:

[video-storyboard-figma-template-longform-30shots.svg](/C:/Users/jyjy6/Documents/New%20project/assets/templates/video-storyboard-figma-template-longform-30shots.svg)

Do not import the markdown guide files. Figma needs the SVG template.

## What changed from the first template

- Built for `16:9` longform content
- Each shot card has a landscape placeholder sized for `1920 x 1080` content ratio
- Expanded from `Shot 01` to `Shot 30`
- Added longform-specific fields like `Act Flow`, `Coverage Balance`, `Theme`, and `Narrative Clarity`

## Suggested Figma page structure

1. `Master 30 Shots`
2. `Alt Coverage`
3. `Kling Outputs`
4. `Final Sequence`

## Recommended use

- Keep the opening, midpoint, and ending payoff easy to scan across the board.
- Use the `Shot Summary` field for the story beat and why the shot matters.
- Replace the frame placeholder with stills from Kling or reference frames as the sequence develops.
