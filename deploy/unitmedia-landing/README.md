# UNITEMEDIA Landing Deploy

이 폴더는 유니트미디어 랜딩페이지의 배포용 정적 파일 묶음입니다.

## 포함 파일

- `index.html`
- `styles.css`

## 바로 배포하는 방법

### Netlify

1. Netlify 대시보드 열기
2. `Add new site` 선택
3. 이 폴더 전체를 드래그앤드롭

### Cloudflare Pages

1. Pages 프로젝트 생성
2. 정적 사이트 업로드 선택
3. 이 폴더를 업로드

### Vercel

1. 새 프로젝트 생성
2. 이 폴더를 정적 사이트로 업로드하거나 저장소와 연결

## 로컬 확인

정적 서버로 열어서 확인하면 됩니다.

예시:

```bash
npx serve .
```

또는 VS Code Live Server 같은 정적 서버를 사용해도 됩니다.
