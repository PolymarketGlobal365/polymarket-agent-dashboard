# Vercel PDF Deploy

이 폴더는 `1440 Fixed.pdf` 파일을 Vercel에서 웹페이지처럼 바로 볼 수 있게 만든 배포용 폴더입니다.

## 포함 파일

- `index.html`
- `1440-Fixed.pdf`
- `pages/page-001.jpg`

## 배포 방법

1. Vercel 로그인
2. `New Project` 또는 `Add New...`
3. 이 폴더 업로드
4. 배포 완료 후 `*.vercel.app` 주소 접속

접속하면:

- 첫 화면에서 PDF 페이지가 이미지로 바로 보임
- `새 탭으로 열기`
- `PDF 다운로드`

둘 다 사용할 수 있습니다.
